# Kitty Lander

A physics-based 2D landing game, inspired by *Monkey Lander* by Totebo.
Pilot a cat-flown saucer, collect every fish to open the landing pad, then
touch down gently on both legs before your fuel runs out.

Made with **Unity 6 (6000.4.8f1)**, URP 2D and the Input System.

## How to play

| Action | Keys | Gamepad |
|---|---|---|
| Main thruster | `W` / `Up` / `Space` | A / right trigger / stick up |
| Steer | `A` `D` / `Left` `Right` | left stick / d-pad |
| Restart level | `R` | |
| Pause | `Esc` / `P` | |
| Next level (after landing) | `N` | |

* The lander waits on the launch spot until you press a key.
* Collect **all fish** to reveal the landing pad.
* Land with **both legs on the pad** and the speed readout **green** (slow).
* Touching terrain or a hazard, or leaving the level, crashes the lander.
* **Cat food** gives a small fuel refill and the **milk bottle** a big one.
* Stars are based on fuel left: 3 stars for 35% or more, 2 stars for 12% or more.
  Progress and stars are saved.

## Project layout

```
Assets/
  Scripts/            runtime code (KittyLander assembly)
    Lander.cs           flight, fuel, landing and crash logic
    GameManager.cs      level rules, stars, pause/restart, per-level settings
    GameUI.cs           HUD + pause / win / crash screens
    MainMenuUI.cs       title screen and level select
    TerrainShape.cs     draws a PolygonCollider2D as textured cartoon terrain
    Hazard.cs           moving / spinning obstacles
    CameraFollow.cs, BackgroundFit.cs, AudioManager.cs, Progress.cs, UIKit.cs, Bobber.cs
  Editor/
    KittyLanderBuilder.cs   "Kitty Lander" menu: rebuild + validate levels
    LevelData/levels.json   level layouts (generated by Tools/level_design.py)
  Art/Generated/      terrain textures, backgrounds, hazards, UI and sound effects
  Prefabs/            Lander, LandingPad, Fish, CatFood, Milk, Hazards/*
  Scenes/MainMenu.unity, Scenes/Levels/Level01-11.unity
  Tests/PlayMode/     end-to-end playthrough tests
Tools/
  generate_art.py     generates the art and sound effects in Assets/Art/Generated
  level_design.py     level layouts -> levels.json (+ optional preview images)
```

## Editing levels

You can edit the level scenes directly in Unity. Terrain is a `PolygonCollider2D`,
so edit its points and the visuals follow.

To change layouts from data instead:

1. Edit `Tools/level_design.py` and run `python Tools/level_design.py`
   (add `--preview some/folder` for quick PNG previews).
2. In Unity choose **Kitty Lander > Rebuild Levels**. This regenerates `MainMenu` and
   `Level01-11` and sets the build scene list. **It overwrites manual edits to those scenes.**
3. Choose **Kitty Lander > Validate Levels**. Using the lander's real size, it checks that
   every fish and the pad can be reached.

To regenerate the art, run `python Tools/generate_art.py` (needs Pillow and NumPy).

## Tests

Open **Window > General > Test Runner > PlayMode** and run all. Each level is loaded,
fish are collected, the pad opens and a landing is performed. Crash, out-of-bounds,
refuel, pause and menu behaviour are covered too.

From the command line:

```
Unity -batchmode -projectPath . -runTests -testPlatform PlayMode -testResults results.xml
```
